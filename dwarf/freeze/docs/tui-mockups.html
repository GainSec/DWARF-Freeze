The default view, modelled on an intercepting proxy. The node is the "server". Everything going into it or moving inside it is an item you can hold, read, edit, forward or drop. Tool tabs run across the top the same way Proxy, Repeater and Intruder do. Node-internal detail is in the Inspector on the right, or one tab over, never in the way.

Where it stops. The node can stop at every single step; you choose how fine that is. Freeze points are conditions, written against Cardano things (slot, block number, peer, tx hash) and not against memory addresses. Cold spots are the named places we decided matter, and each can be switched on as a group.

The piping for later. Everything the screens do goes through one small set of commands (freeze, thaw, step, read, write, inject, drop, subscribe). A tool is any program that speaks those same commands, so new security tests plug in without touching the debugger or the node. This rail lists them; the right side shows one running.
